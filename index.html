      Browser notes and limits
      • Best in Edge or Chrome on Windows. Those browsers let you pick where the file is saved before encoding starts, and handle large files best.
      • Firefox should work but is not tested. The finished file arrives as a normal download.
      • Safari is best effort and not tested. It may fail on large files. If it does, use Edge or Chrome.
      • Keep the tab open and visible while encoding. Closing it stops the job, and background tabs run slowly.
      • Large files need memory: the finished file is held in memory before saving. On computers with 8 GB of RAM, outputs over about 0.8 GB may fail, so prefer H.264 over ProRes for long clips.
      • Browser encoding is slow (a 30 s HD clip can take several minutes). It does not use the graphics card.
      • The first visit downloads about 31 MB for the encoder. It is cached afterwards, and no video ever leaves this computer.
      • The report is a technical check against the preset values. Presets marked UNVERIFIED have not been confirmed with the placement.
      No files leave this machine. Encoder: ffmpeg.wasm (pinned version, bundled with this page).
